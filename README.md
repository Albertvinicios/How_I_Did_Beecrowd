# 🐝 How I Did BeeCrowd

Repositório com resoluções de problemas da plataforma BeeCrowd (URI), desenvolvidas com foco em lógica de programação, clareza de código e aprendizado contínuo.

---

## 🚀 Objetivo

Registrar minha evolução resolvendo problemas algorítmicos, demonstrando:

* Raciocínio lógico
* Estruturação de soluções
* Organização de código
* Consistência na prática

---

## 🧠 Metodologia

Cada problema foi resolvido:

* Com implementação própria
* Priorizando legibilidade
* Com comentários explicativos quando necessário

O foco é mostrar **como eu penso para resolver problemas**, não apenas a resposta.

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/how-i-did-beecrowd.git
```

2. Acesse a pasta do projeto:

```bash
cd how-i-did-beecrowd
```

3. Compile o arquivo Java:

```bash
javac NomeDoArquivo.java
```

4. Execute o programa:

```bash
java NomeDoArquivo
```
